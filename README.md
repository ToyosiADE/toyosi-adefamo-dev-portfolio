# Toyosi Adefamo — Flutter Developer Portfolio

A responsive, static portfolio website built with HTML, CSS, and vanilla JavaScript. It has no build step, backend, paid dependency, or framework requirement.

## Files

- `index.html` — page content and semantic structure
- `style.css` — responsive layout, styles, and decorative project illustrations
- `script.js` — mobile navigation and dynamic footer year

## Preview locally

Open `index.html` in a browser. An internet connection is needed to load the Google Fonts; the website otherwise works as a static page.

## Publish free with GitHub Pages

### Option A: use your existing `ToyosiTY.github.io` repository

1. Download and unzip this portfolio.
2. Open your existing repository: https://github.com/ToyosiADE/ToyosiTY.github.io
3. Review the current files and make a backup before replacing anything.
4. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root. If GitHub asks whether to replace an existing file, confirm only after you have backed up anything you want to keep.
5. Open the repository's **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**, select `main` (or the branch you use) and `/ (root)`, then save.
7. Wait for the deployment to complete. The expected URL for this repository name is https://toyosiade.github.io/ . Confirm it under Settings → Pages; don't assume it is live until GitHub shows the deployment as successful.

### Option B: keep this as a separate repository

1. Create a new **public** repository named `toyosiade.github.io` only if that name is available and you want it to be your account's user site. Alternatively, create any public repository and enable Pages; the URL will then include the repository name.
2. Upload the four files to its root.
3. Enable GitHub Pages in **Settings → Pages** using the `main` branch and `/ (root)`.
4. Open the URL shown by GitHub Pages after deployment.

## Before sharing with recruiters

- Confirm that every linked repository is public and that the link opens while signed out.
- Add screenshots captured from your actual apps; the graphics on this website are decorative illustrations, not screenshots of the apps.
- Update project descriptions only after checking each app's code and confirming the implemented features.
- The Pharmacy App and Coffee Card repositories currently have default Flutter README text, so add project-specific setup steps, screenshots, and a feature list.
- The `mentalhealthapp` repository could not be verified as accessible during the initial audit, so it is intentionally not linked here. Add it only after confirming its exact public URL and that it contains work you are comfortable showing.
- Do not publish private company repositories, secrets, API keys, `.env` files, customer data, or internal screenshots. Work experience can be described at a high level without exposing company code.
- Add a downloadable CV only when you have a current version ready.

## Free hosting

GitHub Pages can host this static website for free on a public repository. It does not run a server-side backend, and the site uses no external form service. The contact button opens the visitor's email application.
