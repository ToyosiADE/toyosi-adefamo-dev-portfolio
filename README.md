# Toyosi Adefamo — Cream Editorial Portfolio

Responsive single-page portfolio redesign with a warm editorial style, a working light/dark mode toggle, and the actual CV PDF included.

## Design palette
- Cream background: `#F4F1EB`
- Near-black text: `#151515`
- Orange accent: `#E64D0C`
- Warm neutral panels: `#EEEAE2` and `#EAE5DC`
- Typography: Manrope + DM Mono

## Files
- `index.html` — portfolio page and content
- `style.css` — layout, visual styling, responsive rules, dark theme
- `script.js` — light/dark toggle and saved theme preference
- `Toyosi-Adefamo-CV.pdf` — actual CV PDF provided for the portfolio

## CV functionality
The navigation includes a CV link. The hero and contact sections include links to view and download the PDF. Keep the PDF in the same directory as `index.html` when deploying this version so the relative links continue to work.

## Preview
Extract the ZIP and open `index.html` in a browser. No build process is required.
